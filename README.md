# moit

약속 관리 및 일정 조율 Flutter 애플리케이션

## 프로젝트 개요

Moit는 그룹 내에서 만남 일정을 조율하고 투표를 통해 날짜와 시간을 결정할 수 있는 애플리케이션입니다.

## 역할 시스템 (Role System)

애플리케이션은 두 가지 역할로 구분됩니다:

- **모임장 (Meeting Host)**: 모임을 처음 생성한 사람. 모임에 대한 관리 권한을 가집니다.
- **모임원 (Meeting Members)**: 초대되어 모임에 참여하는 사람들.

이 역할 시스템은 서버 단에 구현되어 있습니다.

## 주요 기능

- 새 약속 만들기 (모임 이름, 친구 초대, 날짜 선택)
- 날짜 투표 시스템
- 투표 결과 확인 및 날짜 확정
- 시간 투표 기능
- 링크 공유를 통한 초대
